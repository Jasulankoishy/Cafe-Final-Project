# Сообщения для команды

## Участнику 1

Привет! Делаем общий проект «Заказ в кафе» на Java 17. Твои паттерны — Factory Method и Decorator. Сделай абстрактную фабрику с методом createItem(), который возвращает Order.Item, и конкретные фабрики, например BurgerFactory и TeaFactory. Для Decorator сделай обёртку над Order.Item и добавку, например CheeseExtra: она дописывает название и увеличивает цену. Код клади в src/cafe, package cafe, ветка menu-patterns. Покажи, как создать бургер через фабрику, обернуть его добавкой и передать в CafeFacade.placeOrder. Основные классы не меняй.

## Участнику 2

Привет! Делаем общий проект «Заказ в кафе» на Java 17. Твои паттерны — Strategy и Observer. Сделай две реализации CafeFacade.Pricing: RegularPricing и DiscountPricing, обе с методом total(Order). Для Observer сделай класс, который реализует CafeFacade.OrderEvents, позволяет подписать несколько слушателей и в placed(Order, int) уведомляет каждого. Добавь двух слушателей: кухню и кассу. Код клади в src/cafe, package cafe, ветка pricing-events. Покажи, что смена стратегии меняет цену и что оба слушателя получают заказ. Основные классы не меняй.

## Общая демонстрация

После объединения веток соберём один сценарий в Main: фабрика создаёт бургер, декоратор добавляет сыр, фасад вызывает Builder, стратегия считает сумму, Observer уведомляет кухню и кассу. После этого сделаем скриншот общего запуска, UML на шесть паттернов, PDF и ZIP для Moodle.
